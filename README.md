# Learnly — Responsive Product Landing Page

A polished, responsive landing page concept for **Learnly**, a fictional micro-learning platform for students, young professionals, and curious lifelong learners.

## Run locally
1. Extract the ZIP.
2. Open the `figma_product_landing_page` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Resize the browser to see the desktop, tablet, and mobile layouts.

## Design concept
- **Target audience:** Students and early-career professionals who want to build useful skills in short sessions.
- **Visual direction:** Friendly, calm, encouraging and modern.
- **Colors:** Deep ink `#24233D`, purple `#7657E8`, lavender `#F1EDFF`, peach `#FFDFCF`, mint `#D9F3E8`, warm white `#FFFDFB`.
- **Typography:** Plus Jakarta Sans for headings; DM Sans for body text.
- **Layout:** Responsive two-column hero, three feature cards, a steps section, testimonial, CTA and footer.
- **Interactions:** Responsive mobile navigation and hover effects. The CTA is a demo link; there is no backend.

## Figma deliverable checklist
This ZIP is a browser-ready coded reference design. To deliver the required **Figma file**, recreate/import the visual design in Figma and use Auto Layout for:
1. Header: horizontal Auto Layout with logo, navigation and CTA.
2. Hero: horizontal Auto Layout on desktop; vertical on mobile.
3. Feature cards: vertical Auto Layout; place three cards in a horizontal parent Auto Layout.
4. Buttons: horizontal Auto Layout with label and arrow.
5. Footer: horizontal Auto Layout on desktop and vertical on mobile.

Create reusable components for the primary button, feature card, and navigation link. Save the colors and text styles in Figma's local styles. Then share the Figma file link and upload this folder to GitHub.

## GitHub upload
Create a new repository on GitHub, then upload `index.html`, `style.css`, `script.js`, and `README.md`. For a live site, enable GitHub Pages in the repository's Settings → Pages and select the main branch/root folder.
